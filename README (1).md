# Network Stability Checker（Python）

## 概要

指定したWebサイトにHTTP/HTTPSリクエストを複数回送り、応答時間や応答状況を画面上で確認できるデスクトップアプリケーションです。測定結果を一覧で表示し、簡単な統計値を集計してCSVファイルに保存できます。

## 主な機能

- 測定先URLと測定回数（1～100回）の指定
- HTTP/HTTPSリクエストによる応答時間の測定
- 各測定の時刻、HTTPステータス、応答時間、エラー情報の表示
- 成功率、平均・最短・最長応答時間の集計
- 成功した測定の応答時間を使った簡易的な変動幅の計算
- 測定の停止
- 測定結果のCSVファイルへの保存

## 使用技術

- Python 3.10以降を推奨
- Tkinter / ttk：デスクトップ画面の作成
- `urllib.request`：HTTP/HTTPSリクエスト
- `threading`：画面操作と通信測定の並行処理
- `queue`：測定スレッドから画面側への結果の受け渡し
- `statistics`：平均値などの統計処理
- `csv`：測定結果の保存

Pythonの標準ライブラリを使用しているため、追加の `pip install` は不要です。Tkinterが利用できるPython環境が必要です。

## 起動方法

ソースコードがあるフォルダで、次のコマンドを実行します。

```bash
python network_stability_checker.py
```

Windowsで `python` が認識されない場合は、次を試してください。

```powershell
py network_stability_checker.py
```

## 使い方

1. 測定先のURLを入力します（初期値はPlayStation公式サイトです）。
2. 測定回数を1～100回の範囲で指定します。
3. 「測定開始」を押すと、測定結果が一覧に追加されます。
4. 必要に応じて「停止」を押して測定を中断できます。
5. 測定後に「CSVに保存」を押すと、結果をファイルに出力できます。

## 指標について

- **成功率**：HTTP応答を受け取った回数の割合です。HTTP 4xxや5xxの応答も、サーバーから応答が返った場合は成功として数えます。
- **平均・最短・最長応答時間**：HTTP応答を受け取るまでにかかった時間です。
- **応答時間の変動幅**：成功した測定の応答時間を並べたときの、隣り合う値の差の絶対値の平均です。ネットワーク分野で用いられるジッターの厳密な測定値ではなく、変動を把握するための簡易指標です。

## 注意事項・制限

- このアプリは一般的なWebサイトへのHTTP/HTTPS応答を測定するものです。
- 測定値は接続先サーバーの負荷、DNS、インターネット経路、PCの状態、測定する時間帯などに左右されます。
- 測定先の利用条件に配慮し、短時間に過度な回数のアクセスを行わないでください。

## 制作について

PythonのGUI作成、HTTP/HTTPS通信、例外処理、スレッド処理、キューによるデータ受け渡し、統計処理、CSV出力を学ぶために作成した個人学習用のプログラムです。制作過程では生成AIを補助的に利用しています。
