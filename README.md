# Network Stability Checker (Python)

指定したWebサイトへのHTTPS応答を繰り返し測定し、応答時間と簡単な安定性指標を表示するTkinterデスクトップアプリです。標準ライブラリのみを使用します。

## 必要なもの

- Python 3.10以降を推奨
- Tkinter（Windows用の通常のPythonインストーラーでは一般に利用できます）
- インターネット接続

追加のpip installは不要です。

## 起動方法

1. `network_stability_checker.py` を保存します。
2. VS Codeでファイルがあるフォルダを開きます。
3. ターミナルで次を実行します。

```bash
python network_stability_checker.py
```

Windowsで `python` が認識されない場合は、次を試してください。

```powershell
py network_stability_checker.py
```

## 使い方

1. 測定先URLを入力します（初期値はPlayStation公式サイト）。
2. 測定回数を1～100回で指定します。
3. 「測定開始」を押します。
4. 結果の概要と測定履歴を確認します。
5. 必要に応じて「CSVに保存」を押します。

## 指標の説明

- 成功率：HTTP応答を受け取れた回数の割合。HTTP 4xx/5xxもサーバーから応答が返った場合は通信成功として扱います。
- 平均・最短・最長応答時間：HTTP応答を受け取るまでの時間。
- 応答時間の変動幅：連続する成功測定の応答時間の差の絶対値の平均（簡易ジッター指標）。

## 注意事項と限界

- このアプリは一般的なHTTP/HTTPSの応答を測定するものです。PlayStation Portalの専用ストリーミングサーバーへの経路、ゲーム内の入力遅延、映像・音声品質、Wi-Fiの電波品質を直接測定するものではありません。
- 測定値は測定先サーバーの負荷、DNS、インターネット経路、PCの状態などにも左右されます。
- 同じURLでも時間帯やネットワーク環境によって結果は変わります。
- 測定先の利用規約や負荷に配慮し、短時間に過度な回数のアクセスを行わないでください。
